# Как помочь проекту

Спасибо, что хотите сделать OpenPaste лучше! Изменения принимаются через pull request: напрямую в `main` писать нельзя.

## Порядок

1. Сделайте форк репозитория и создайте ветку от `main`.
2. Внесите изменения и убедитесь, что всё собирается и тесты проходят:
   ```sh
   swift test
   ./build.sh && open OpenPaste.app
   ```
3. Откройте pull request и опишите, что и зачем изменилось. Для изменений в интерфейсе приложите скриншот.

Для сборки нужны macOS 14+ и Xcode 26 или новее.

## Что стоит знать

- Новая логика (ветвления, разбор данных, работа с файлами) сопровождается тестом в `Tests/OpenPasteTests`.
- Проект без внешних зависимостей. Перед добавлением библиотеки откройте issue и обсудите.
- Не коммитьте личные данные: содержимое своего буфера обмена, сертификаты, ключи, пути вида `/Users/<имя>`.
- Для крупных изменений сначала откройте issue, чтобы не делать работу впустую.
